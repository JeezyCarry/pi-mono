A reviewer that cannot answer now says so loudly. An untyped, non-refusal error — a wiring bug, an SDK-internal failure the lane never typed — is availability on its face, so the pool fails over to the backup instead of deferring on the spot. The review log carries the thrown value's class name (`TypeError`, never the message, which can hide a URL or a key), so an operator reads whether the guard was broken without the debug stream. And a machinery defer (anything but the model's own `model-defer`) credits the breaker's consecutive tier even when the mode routes it to a human ask, so three straight failures trip where before a broken guard asked forever. Every classifier exit now carries its risk label too, so risk can be graded from the review log rather than only from deny records.
