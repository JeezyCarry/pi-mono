# 0007 — the model answers observable questions; code decides

- Status: accepted.
- Context: the five-axis protocol asked the model for judgments it cannot make. `observation` fused action, location and certainty into one axis whose confidence was itself the auto-pass gate, so `nproc` and `npx vite` lost on a coin-flip label; `destructive_vcs` asked whether a branch was seen by others or a copy was regenerable, which the command text does not say; and `auth` had no "no anchor exists" option, so the model answered a question the code already knew. Measurement agreed: `unsafe-allow` was already 0 on the corpus, the failures were almost entirely benign commands asked about one extra time, and wording rounds were exhausted on evidence (arms A/B/C/D all failed honestly). An independent reader labelling the then-208-command corpus disagreed with the hand-written labels on 68 of them for `target` alone, which is the strongest evidence that the axis asked for more than the text contains.
- Decision: the model answers only what the record shows — `ban` (is an in-force prohibition in the trusted record), `effect` (the heaviest action), `target` (what kind of thing it touches), and, only when a trusted anchor exists, `intent` (did the request name this action and stay inside it). Everything deterministic moves to code: path scope, build-output names, sensitive names, history rewriting, network reach, and whether an anchor exists at all. A pure decision table turns a four-level base tier plus an authorization adjustment into exactly one of five verdicts, and it never reads the mode. The mode ladder then maps that verdict, unchanged from before. Corpus expectations derive from a blind impact record — what actually happens if the command runs — never from the rule set or the policy clauses, so the rule set cannot certify itself.
- Consequences: `observation`, `auth`, and the split block/confirm tier names are retired, not aliased; the deny authority rule is unchanged and still comes from 0006 (a screen deny is hard, every model deny is soft); the model's self-reported risk and confidence stay audit evidence, and confidence only ever suppresses a positive label, never licenses one. A case whose category depends on state the text cannot show is rewritten until it carries the state, rather than being judged on it.
- Alternatives considered: keep the five axes and keep tuning wording (rejected — exhausted on evidence, and three of four wording arms failed); let the model produce the verdict directly (rejected — 0006 keeps deny authority with the screen); derive expectations from policy clauses (rejected — this is the loop the corpus has to break, because the clause and the rule set share an author); split `observation` into three axes without moving judgment into code (rejected — it keeps the model judging branch visibility).
